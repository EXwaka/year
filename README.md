這是我首次接觸大型專案的第一份工項，也是接觸最多新工具的時候。
第一個遇到的困難是更換圖片，這段時間也從其他同仁那邊學到如何用TexturePacker包圖跟更換圖片，而當時我以為只要直接為物件更換圖片就好，但遊戲內圖片都沒換到，自己摸索一段時間才知道專案內有使用代碼調用方法來更換圖片。
同時知道還有多國版本的美術圖片需要更換，也是在這邊開始熟悉不同語系換圖會碰到的問題(不同語系圖片大小不同需要根據語系調整位置、大小等)。
完成後的發版測試還需要知道要更新哪些資源包避免不必要的浪費。

工作內容：

商城是我第一個實作NGUI to UGUI的優化項目，也是第一個較大的優化項目，這次的困難點是全面把一個NGUI的UI介面替換成UGUI的物件跟代碼寫法，在這裡也花了不少時間摸索NGUI跟UGUI這兩種使用方法的差異，也在這裡認識到還有分ios、android跟Download apk這三種不同環境對應不同的介面跟流程(ios跟android使用相同介面download版有自己的網頁介面)，在這裡碰到了不少困難。
在實作期間出現了新的問題大概也是我這一年中碰到最大的困難之一，由於當時只有要求修改金幣商城的介面，在接近截止日期前才發現籌碼館也有一個跟金幣商城共用同一個管理腳本的籌碼商城，由於時間抓得很緊，跟主管還有美術人員確認後才加班把籌碼商城也一起做優化改版(值得慶幸的是兩種商城的架構相差不大)。

### 工作內容

- 調整 UI 排版
- 更換美術資源
- NGUI 改版至 UGUI

這三個項目原本是分開的，但登入功能同時會影響到綁定相關流程，所以同時一起做改版。這是我全部工項中實作過最大的一次改版，它涉及大量介面與遊戲場景，從登入畫面到進入大廳還有進入遊戲的加載，還要確保登入流程沒有問題避免玩家連遊戲都不能玩，每一個部分都跟以往的NGUI改UGUI優化不同，加上登入畫面是一次要修改整個遊戲場景，不再是單一的物件，所以很多地方的作法是沒有作業可以抄的，像是登入畫面我是根據自己的想法在現有的場景管理腳本來重建這個全UGUI的登入場景。

我花了不少時間使用AI輔助跟觀察其他人在遊戲場景的配置，當時測試出來的版本連登入畫面換皮本身都有很多問題，例如場景中的相機也要為了UGUI畫面一起做調整避免變形，但經過這一年的累積讓我能夠更快的理解這些結構龐大的腳本代碼背後都代表甚麼行為方法，也很順利的解決了許多困難。
雖然最後完成版本出現了意想不到的東南亞限定的遊戲登出卡住錯誤，當時我以為是場景管理的腳本的問題所以用了一種不合適但可運行的方式修正，感謝同仁後來的協助，排查出是在實作中漏掉了一個沒優化到的物件(看起來像是停用已久的LOGO動畫)，完成了這個項目。

## 7.其他
### Bug修正
除了較大的優化改版項目外不時會分配一些小Bug問題需要修正，大多在處理上沒有太多困難，有少數問題比較難確認處裡的必要(例如可能是因為個別特定裝置在遊戲中突然掉光字體，或是從沒在正式版本發布過的功能修正)這些都要跟分配的人員通知處理上的困難跟疑惑。

### 實作
在這一年間除了工項外我也對專案裡的工具腳本很感興趣，也有在家裡試著復刻相同的功能，例如素材資源加載(Asset Resource Load)，TortoiseGit的專案追蹤工具，還有我最感興趣的節省圖片資源打包(TexturePacker)跟把Spine動畫應用在unity裡，我自己嘗試做出了一個動畫功能，讓這個Spine動畫可以跟隨玩家的動作來做播放行為想在未來能應用在一些互動式動畫上。
