📌工作內容：
- 調整UI排版
- 更換美術圖
- NGUI改版UGUI

 🚧 困難與解決
- 第一次NGUI轉UGUI完整介面改版，重新理解兩套UI系統在配置、事件及程式撰寫方式上的差異。
- 認識不同平台(iOS、Android、Download APK)有不同的介面與流程，避免改版後造成特定版本異常。
- 理解美術資源從下載、載入到顯示的流程，透過閱讀既有程式碼與工具輔助來理解架構。
- 中途發現有超出原規劃範圍外的功能也需要同步進行優化，經過與相關人員確認後，調整開發安排。

商城是我第一個實作NGUI to UGUI的優化項目，也是第一個較大的優化項目，這次的困難點是全面把一個NGUI的UI介面替換成UGUI的物件跟代碼寫法，在這裡也花了不少時間摸索NGUI跟UGUI這兩種使用方法的差異，也在這裡認識到還有分ios、android跟Download apk這三種不同環境對應不同的介面跟流程(ios跟android使用相同介面download版有自己的網頁介面)，在這裡碰到了不少困難。
在這裡我也第一次接觸到圖片下載跟串接方法流程，這些方法一開始很難理解，後來是用了AI輔助才理解背後的原理。

在實作期間出現了新的問題大概也是我這一年中碰到最大的困難之一，由於當時只有要求修改金幣商城的介面，在接近截止日期前才發現籌碼館也有一個跟金幣商城共用同一個管理腳本的籌碼商城，由於時間抓得很緊，跟主管還有美術人員確認後才加班把籌碼商城也一起做優化改版(值得慶幸的是兩種商城的架構相差不大)。

我花了不少時間使用AI輔助跟觀察其他人在遊戲場景的配置，當時測試出來的版本連登入畫面換皮本身都有很多問題，例如場景中的相機也要為了UGUI畫面一起做調整避免變形，但經過這一年的累積讓我能夠更快的理解這些結構龐大的腳本代碼背後都代表甚麼行為方法，也很順利的解決了許多困難。
雖然最後完成版本出現了意想不到的東南亞限定的遊戲登出卡住錯誤，當時我以為是場景管理的腳本的問題所以用了一種不合適但可運行的方式修正，感謝同仁後來的協助，排查出是在實作中漏掉了一個沒優化到的物件(看起來像是停用已久的LOGO動畫)，完成了這個項目。

### 📌工作內容
- 調整 UI 排版
- 更換美術資源
- NGUI 改版至 UGUI

 🚧 困難與解決
- 部分畫面與規格書範例存在差異，與企劃、美術人員確認後進行調整。
- 使用Find Reference工具找出所有依賴關係避免遺漏。
- 部分物件需要等待美術重新提供資源才能替換，與主管、美術人員討論後調整，拆分成兩次版本更新。

付費敲蛋作為較後期我相對順利的項目之一，NGUI改版UGUI過程上幾乎沒碰到問題，期間只有發現部分與規格書上的範例有差異，與企劃跟美術人員溝通後做了些許調整。

在金幣換皮項目期間較多的困難是找出專案內全部有使用到金幣圖案的任何物件，且全部替換成一個共用的圖片以便未來做統一更換，我使用了專案的工具(Find Reference)尋找任何跟舊金幣圖片有依賴關係的物件，其中包含了靜態、動畫跟特效物件，加上不少物件需要美術協助重新出圖才能替換，在與主管討論後決定分成兩次更新版本，第一次著重在靜態且可以直接替換圖片的物件上做修改，第二次則是等待美術完成後與動態物件一起替換。

## 9.其他
### Bug修正
除了較大的優化改版項目外不時會分配一些小Bug問題需要修正，大多在處理上沒有太多困難，有少數問題比較難確認處裡的必要(例如可能是因為個別特定裝置在特定條件下才會發生的引擎或裝置本身問題，又或是從沒在正式版本發布過的功能修正)這些都要跟分配的人員通知處理上的困難跟疑惑。
